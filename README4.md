# Tech Stack

This project is built with a modern web stack designed for a fast, interactive learning experience.

## Frontend
- Next.js - React framework for server-rendered and static web applications.
- React - JavaScript library for building user interfaces.
- TypeScript - Strongly typed programming language that improves code reliability.
- Tailwind-inspired UI components - Reusable interface components for a polished experience.

## Backend / API
- Next.js API Routes - Serverless API endpoints for handling app logic.
- Supabase - Backend-as-a-Service for authentication, database, and real-time features.

## AI / Content Processing
- OpenAI/Grok-style AI integration - Used for generating educational content and feedback.
- Custom AI service layer - Handles prompts, parsing, and response processing.

## Data / Storage
- Supabase Database - Stores user and application data.
- Local JSON storage - Used for lightweight time-tracking and local data handling.

## Other Tools
- Middleware - Used for request handling and route protection.
- TypeScript configuration and environment management - Helps keep the app structured and secure.
